## Publish with GitHub Pages
This repository is named `pandeynikhilone.github.io`. To publish it:
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch `main` and folder `/(root)`, then Save.
4. Wait for the Pages deployment and open https://pandeynikhilone.github.io.

If Pages is already enabled, a new commit to `main` should update the site.
